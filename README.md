  HR.ServiceA — веб-сервис для управления персоналом
  1. Назначение проекта
  HR.ServiceA — веб-сервис, разработанный на платформе ASP.NET Core Web API с использованием языка программирования C# и .NET 8.
  Сервис предназначен для выполнения операций, связанных с управлением персоналом: получения информации о сотрудниках, добавления сотрудников, прогнозирования кадровых рисков, расчёта нагрузки подразделений и оценки кандидатов.
  2. Основные функции API
  В проекте реализованы следующие HTTP-методы:
  Получение сотрудников(`GET /api/Employees`) - Возвращает список сотрудников.
  Добавление сотрудника (`POST /api/Employees`) - Добавляет нового сотрудника.
  Прогноз кадрового риска (`POST /api/Employees/forecast`) - Рассчитывает прогноз кадрового риска.
  Расчёт нагрузки подразделения (`POST /api/Load/department`) - Выполняет расчёт нагрузки подразделения.
  Оценка кандидатов (`POST /api/Candidates/score`) - Рассчитывает оценки кандидатов.
  3. Технологии проекта
  В разработке использованы:
  - C#;
  - .NET 8;
  - ASP.NET Core Web API;
  - Swagger UI;
  - Swashbuckle.AspNetCore;
  - XML-комментарии для документирования API;
  - Docker для контейнеризации приложения.
  4. Архитектура проекта
  Проект имеет следующую структуру:
  - `Controllers` — контроллеры, обрабатывающие HTTP-запросы;
  - `Models` — модели данных и классы запросов и ответов;
  - `Services` — сервисы с логикой расчётов и обработки данных;
  - `Program.cs` — настройка приложения, регистрация сервисов и Swagger.
  Для хранения сотрудников используется временный статический список в памяти приложения. Отдельная база данных в текущей реализации не подключена.
  5. Документирование API
  Для автоматической генерации документации подключён Swagger.
  В проекте включено формирование XML-файла документации. XML-комментарии добавлены к контроллерам, методам, моделям и их свойствам.
  Swagger UI позволяет просматривать доступные маршруты, HTTP-методы, параметры запросов, модели данных и ответы API.
  Локальный адрес Swagger UI:
  `https://localhost:7003/swagger`
  6. Запуск проекта
  Для локального запуска необходимы установленная среда .NET 8 SDK и исходный код проекта.
  1. Склонировать репозиторий:
     git clone https://github.com/Kiko-Ekaterina-5k/HR.ServiceA.git
  2. Перейти в каталог проекта:
     cd HR.ServiceA
  3. Запустить приложение:
     dotnet run
  4. Открыть Swagger UI по адресу, указанному в консоли запуска. В используемой конфигурации локальный адрес — `https://localhost:7003/swagger`.
